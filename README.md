# The Foresters — Brand Menu Demo

Digital menu screen that applies colours extracted from the restaurant logo upload API.

## Theme source

Uses the logo palette response:

- Background / accent: `#1f3822`
- Item text: `#FFFFFF`
- Ingredient text: `#E0E0E0`
- Logo: DigitalOcean Spaces CDN

## Run

```bash
cd menu-app
npm install
npm run dev
```

Open the local Vite URL to view the menu.
